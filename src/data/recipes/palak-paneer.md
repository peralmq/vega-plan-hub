## Ingredients

| quantity | unit | key          | ingredient              | notes                          |
| -------- | ---- | ------------ | -------------------------| --------------------------------- |
| 500      | g    | spinach      | färsk spenat              | eller samma mängd fryst, tinad   |
| 2-3      | dl   | water        | vatten                    | efter behov för mixning          |
| 1        |      | green-chili  | grön chili, finhackad     |                                   |
| 2        |      | garlic       | vitlöksklyftor, finhackade|                                   |
| 2        | tbsp | ginger       | färsk ingefära, hackad    |                                   |
| 0.5      | dl   | oil          | neutral olja              | för temperering                  |
| 1        | tsp  | cumin-seeds  | hela kumminfrön           |                                   |
| 1        |      | onion        | gul lök, finhackad        |                                   |
| 0.5      | tsp  | turmeric     | gurkmeja                  |                                   |
| 0.5      | tsp  | chili-powder | chilipulver                |                                   |
|          |      | hing         | hing/asafetida             | valfritt                         |
| 0.5      | tsp  | garam-masala | garam masala                |                                   |
| 1        | tsp  | salt         | salt                        |                                   |
| 400      | g    | paneer       | paneer eller fast tofu, tärnad |                              |
|          |      | rice         | kokt ris                    | att servera med                  |
|          |      | naan         | naan eller roti/chapati     | valfritt                         |

## Instructions

1. Lägg spenat, chili, vitlök, ingefära och lite av vattnet i en mixer. Mixa till en slät, tjock puré, tillsätt precis så mycket vatten som behövs för att mixa.
2. Hetta upp olja i en stekpanna och stek kumminfröna tills de doftar. Tillsätt lök och fräs tills den mjuknat. Tillsätt gurkmeja, chilipulver, hing och garam masala, och stek i en minut.
3. Tillsätt spenatpuréen, blanda väl och låt sjuda i cirka 10 minuter tills den tjocknat. Om den är för lös, låt sjuda längre för att reducera. Smaka av med salt.
4. Stek paneer- eller tofukuberna tills de är gyllene. Rör ner i spenatsåsen.
5. Servera varm med ris, naan eller roti/chapati. 🌱🧀

## Notes

- Veganskt: använd tofu istället för paneer.
- För extra smak, tillsätt en skvätt citronsaft innan servering.
- Justera chilimängden efter smak för mer eller mindre hetta.
- Den här rätten är naturligt glutenfri och kan göras helt vegansk!
