## Ingredients

| quantity | unit | key            | ingredient       | notes                 |
| -------- | ---- | -------------- | ------------------| --------------------- |
| 2        |      | onion          | gula lökar          |                       |
| 1        | tsp  | smoked-paprika | rökt paprikapulver   |                       |
| 4        | dl   | oat-cream      | havregrädde            | eller annan växtbaserad grädde |
| 1        |      | veg-bouillon   | grönsaksbuljongtärning  |                       |
| 600      | g    | green-peas     | frysta gröna ärtor       |                       |
| 4        | port | pasta          | pasta                     |                       |
|          |      | salt           | salt                        | efter smak            |
|          |      | black-pepper   | svartpeppar                  | efter smak            |
|          |      | oil            | olja                          | för stekning           |
|          |      | vegan-cheese   | vegansk ost                    | valfritt, till topping |

## Instructions

1. Börja koka upp vatten till pastan.
2. Finhacka löken. Hetta upp olja i en stekpanna och fräs löken med rökt paprikapulver tills den är väldigt mjuk.
3. Tillsätt havregrädden och smula i buljongtärningen. Tillsätt ärtorna.
4. Koka pastan enligt förpackningsanvisningarna.
5. När pastan nästan är klar, häll av och tillsätt den i såsen. Låt den bli klar i såsen.
6. Smaka av med salt och rikligt med svartpeppar. Servera med vegansk ost om du vill. 🍝🌱

## Notes

- Snabb, krämig och god vardagspasta! ✨
- Rökt paprikapulver ger en härlig smak.
- Toppa med extra ärtor eller örter.
- Bra för matlådor.
